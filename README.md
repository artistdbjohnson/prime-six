# Prime 6 — dglxss Path A

Motionsites `creative-studio` fuel-system pitch for [prime-six.com](https://www.prime-six.com/).

The chassis keeps the creative-studio craft: full-bleed muted fire loop, uppercase Inter, right-aligned stats, bottom-pinned sample CTA, and a matte price-calculator pattern remapped to hospitality fuel units. Accent is the live logo orange `#DF5826`. Opening is the Axiom ember-hex ignition, once per session.

EN is the default. PT and dark/light sit in the header.

```bash
npm install
npm run dev
npx next build
```
